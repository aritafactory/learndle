Как играть?

У вас есть 6 попыток, чтобы угадать скрытое слово. Цвета букв показывают ваш прогресс:

  • Правильное место
  • В слове, но не на своем месте
  • Нет в слове

Интерфейс:

  • Используйте клавиатуру или экранные клавиши для ввода.
  • ENTER - для отправки слова, ⌫ - для удаления букв.
  • Использование подсказок тратит общие очки.

Подсказки:

  • Часть речи — показывает часть речи слова.
  • Пример предложения — показывает пример использования с пропуском вместо слова.
  • Синоним / Антоним — если есть.
  • Определение — показывает определение слова.
  • Показать буквы — показывает какие буквы есть в слове.
  • Открыть букву — показывает и ставит на своё место случайную букву из слова; количество использований не ограничено, но цена растёт с каждым кликом.
